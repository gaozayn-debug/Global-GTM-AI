# User stories / 用户故事

| 用户诉求 / Story | 验收 / Acceptance |
|---|---|
| 我想先体验 / Try first | 点击示例立即产生完整结果 / one click produces results |
| 我想用自己的产品 / My product | 名称、市场、成本可编辑且结果更新 / edits update results |
| 跨币采购 / Cross-currency | 显式方向与数值，切换币种需重填 FX / explicit FX |
| 判断定价 / Pricing | 保本价与目标贡献率价格由方程反解 / solved thresholds |
| 判断广告 / Acquisition | 固定 CAC 上限保持广告比例不变 / explicit basis |
| 避免扩大亏损 / Avoid scaling losses | 非正贡献时暂停建议 / pause on nonpositive contribution |
| 渠道比较 / Channels | 自定义费率与 CAC 实时比较 / custom fee comparison |
| 带走结果 / Export | TXT、CSV 与 JSON 下载按钮有处理器 / actual downloads |
| 恢复项目 / Restore | 初始化先读取草稿再写入 / read before persist |
| 载入失败 / Bad import | 显示错误，不替换当前有效项目 / preserve valid state |
